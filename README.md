# Giraffe and DeepChess Models for Computer Chess

This repository contains implementations of models trained based on the architectures described in the Giraffe and DeepChess papers. You can find the model training code and experimental results in the `.ipynb` notebooks.

### Resources:
- [Giraffe Paper](https://arxiv.org/pdf/1509.01549)
- [DeepChess Paper](https://arxiv.org/pdf/1711.09667)

### Web Application:
A simple web application has been created and can be run locally. Instructions for running the app are available in the `app` folder.
